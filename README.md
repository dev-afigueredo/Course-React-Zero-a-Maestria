# Estudos de React

Repositório pessoal para acompanhar estudos e práticas com React. O conteúdo está organizado em módulos e desafios, que podem crescer conforme o curso avança.

## Organização

- `1_INTRO`: introdução ao React.
- `2_FUNDAMENTOS`: conceitos fundamentais.
- `DESAFIOS`: exercícios práticos.

Cada pasta de projeto é independente e possui suas próprias dependências.

## Como executar

Entre na pasta do projeto desejado, instale as dependências e use o script de desenvolvimento definido no `package.json`:

```bash
cd caminho/do/projeto
npm install
npm start
```

O comando de desenvolvimento pode variar conforme a ferramenta usada pelo projeto, por exemplo `npm start` ou `npm run dev`.

## Requisitos

- Node.js
- npm
